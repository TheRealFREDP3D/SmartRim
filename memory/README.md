# RimWorld Knowledge Base

This directory maintains a growing knowledge base from web research and gameplay experimentation.

## Structure

| File | Content |
|------|---------|
| `beginner-guide.md` | Core beginner strategy, day-by-day plans, checklists |
| `mechanics.md` | Game mechanics deep-dives (wealth, mood, combat, etc.) |
| `colonist-management.md` | Work priorities, scheduling, gear, mood tips |
| `base-design.md` | Base layout, killbox, freezer, room design patterns |
| `combat.md` | Raid handling, weapon tiers, defensive strategies |
| `research-tree.md` | Tech tree priorities, key unlocks, research order |
| `dlc/royalty/` | Royalty DLC notes |
| `dlc/ideology/` | Ideology DLC notes |
| `dlc/biotech/` | Biotech DLC notes |
| `dlc/anomaly/` | Anomaly DLC notes |
| `lessons-learned.md` | Mistakes we made and what we learned from them |
| `session-logs/` | Per-session detailed logs of decisions and outcomes |

## Conventions

- Each file uses headers for easy navigation
- Append new findings at the end of relevant sections
- Date-stamp entries when adding new information
- Cross-reference between files with `see [filename](#section)`

## Run data (gitignored)
- `memory/snapshots/` and `memory/debriefs/` are gitignored (runtime data).
- Archive a completed run by copying its snapshots + debrief into `memory/session-logs/` or a dated folder before starting the next colony, so the survival baseline is preserved.
