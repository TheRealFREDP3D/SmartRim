[![Rimworldlogo.png](/images/thumb/8/8c/Rimworldlogo.png/600px-Rimworldlogo.png)](/wiki/Main_Page "Main Page") **[RimWorld](https://rimworldgame.com)** is an indie space colony management game developed by **[Ludeon Studios](https://ludeon.com/blog/)**, a Canadian-based game studio founded by **[Tynan Sylvester](https://tynansylvester.com/)**.  
Read more about the game at [About RimWorld](/wiki/About_RimWorld "About RimWorld").

  
The current stable versions are [![Content exclusively from the PC Edition](/images/thumb/8/89/PC.png/16px-PC.png)](/wiki/PC_edition "Content exclusively from the PC Edition") **[1.6.4850](/wiki/Version/1.6.4850 "Version/1.6.4850")** and [![Content exclusively from the Console Edition](/images/thumb/6/6e/Console.png/16px-Console.png)](/wiki/Console_edition "Content exclusively from the Console Edition") **[1.23](/wiki/Console_version/1.23 "Console version/1.23")** , and a complete version history can be found via the [Version history](/wiki/Version_history "Version history") page. 

For info on releases, see the [![LudeonLogoSquare.png](/images/thumb/7/7d/LudeonLogoSquare.png/16px-LudeonLogoSquare.png)](https://ludeon.com) [Ludeon development blog](https://ludeon.com) and [![Double Eleven Logo Only.png](/images/thumb/d/de/Double_Eleven_Logo_Only.png/16px-Double_Eleven_Logo_Only.png)](https://rimworld.double11.com/patch-notes) [Double Eleven Patch Feed](https://rimworld.double11.com/patch-notes) respectively.
